# Android TV وMi Box والجودة التلقائية — preview.5

هذا التحديث يبني على تغييرات طلب الدمج #32 التي دُمجت أثناء العمل، ويضيف دعماً تمهيدياً للتلفزيون والبث التكيفي. الإصدار `2.0.0-preview.5`، ورقم Android هو `11`. تحديث preview.5 في طلب مراجعة مستقل ولم يُدمج؛ لا يعني تجهيز APK أن التحديث نُشر تلقائياً على أجهزتك.

## ما الذي تغير؟

- يظهر التطبيق في قائمة Android TV عبر `LEANBACK_LAUNCHER` وصورة دخول للتلفزيون. اللمس غير مطلوب في البيان.
- تظهر علامة تركيز واضحة على أزرار الواجهة عند التنقل بالريموت أو لوحة المفاتيح، وتكبر مساحة الفيديو على التلفزيون. أزرار التشغيل والإيقاف والتقديم والترجيع قابلة للتركيز.
- يفضّل تشغيل يوتيوب وضع `Auto · adaptive up to 1080p` عندما تتوفر مسارات AVC/H.264 متعددة مفهرسة مع صوت AAC. يجمعها التطبيق في مجموعة DASH واحدة؛ يختار Media3 معدل البت حسب سرعة النقل الفعلية. لا يُقاس ذلك بعدد أشرطة إشارة Wi-Fi.
- إذا وفر المصدر HLS، يستطيع محرك التشغيل التكيف عندما تكون قائمة HLS متعددة الجودات. تبقى الجودات اليدوية متاحة، ولا يتحول التنزيل إلى تنزيل DASH تلقائي.
- رابط MP4 منفرد أو مصدر لا يتيح جودات متعددة يبقى بجودة ثابتة؛ لا يستطيع التطبيق إنشاء جودات غير موجودة. البث المقيد أو الخاص أو المحمي ليس مدعوماً عبر تجاوز الحماية.

الحد الأدنى هو **Android 7.0 / API 24**. بعض أجهزة Mi Box تعمل بنظام 32 بت رغم أن المعالج 64 بت؛ لذلك استخدم **Universal APK** وليس ملف ARM64 فقط. أجهزة Android 6 تحتاج تحديث النظام أولاً. دعم التلفزيون هنا ليس شهادة اعتماد لجميع أجهزة Mi Box أو للنشر في متجر Google TV.

## البناء من Windows وPowerShell

استخدم متطلبات JDK 17 وNode 24 وAndroid SDK الموضحة في [دليل Windows](WINDOWS_BUILD.md). احفظ تعديلاتك المحلية قبل تغيير الفرع:

```powershell
cd C:\src\Harmonia-Player
git status --short
git fetch origin
git switch --create review/harmonia-tv-preview5 --track origin/feat/harmonia-tv-adaptive-preview5
npm.cmd ci
npm.cmd run typecheck
npm.cmd test
powershell -NoProfile -ExecutionPolicy Bypass -File .\scripts\build-android-release.ps1 -Mode universal -SkipInstall
```

الملف الناتج: `artifacts\Harmonia-Player-universal.apk`. يتضمن ARM32 وARM64 وx86 وx86_64، ويحتوي JavaScript بداخله؛ لا يحتاج إلى تشغيل Metro. افتح مجلد `android` المولد في Android Studio ثم نفّذ Gradle Sync إذا أردت التطوير من Android Studio.

للتثبيت عبر اتصال ADB مصرح به بجهازك:

```powershell
adb devices
adb install -r .\artifacts\Harmonia-Player-universal.apk
adb shell am start -n com.alhudar.harmonia/.MainActivity
```

اختر الجهاز بـ `adb -s SERIAL` إذا كان لديك أكثر من جهاز. تحقق من ظهور `preview.5` في التطبيق. حزم التطوير موقعة للاختبار؛ إذا رفض Android التحديث لاختلاف التوقيع، استخدم جهاز اختبار أو نسخة موقعة بالمفتاح المطابق. لا تحذف تطبيق الإنتاج وبياناته لحل اختلاف التوقيع.

## اختبار Mi Box المطلوب

1. افتح التطبيق من قائمة التلفزيون دون فأرة، وتنقل بين الرئيسية والبحث والمكتبة والإعدادات بالريموت. تحقق من وضوح التركيز والرجوع دون فقد التنقل.
2. افتح رابطاً عاماً مسموحاً، وشغّل الفيديو والصوت، ثم جرّب الإيقاف والمتابعة والتقديم والترجيع وملء الشاشة والصوت عبر HDMI.
3. اختر «تلقائي» لفيديو يوفر عدة جودات. خفّض سرعة الاتصال من الراوتر أو شبكة اختبار، ثم أعد رفعها. راقب استمرار التشغيل وتغير المسار؛ تغيير الجودة يحتاج عينات نقل ووقتاً، ولا يحدث فور تغير إشارة Wi-Fi.
4. جرّب اختيار جودة ثابتة ثم الرجوع إلى «تلقائي»، والتنزيل بجودة ملف محددة. جرّب أيضاً رابط MP4 منفرداً؛ لا تتوقع منه تغير الدقة تلقائياً.
5. جرّب العربية والإنجليزية، وقطع الإنترنت ثم استعادته، وإعادة تشغيل التطبيق وتشغيل الملفات المحفوظة دون اتصال.

## حدود التحقق

اختبار لوحة المفاتيح في Chromium لا يثبت عمل ريموت Mi Box الفعلي، وبناء المكتبات لكل المعماريات لا يثبت توافق كل وحدة فك ترميز. لا يوجد جهاز أو محاكي متصل في بيئة العمل. محاولة اكتشاف فيديو يوتيوب عام مفتوح الترخيص توقفت بسبب `403 CONNECT` من وكيل شبكة البيئة، قبل الوصول إلى يوتيوب؛ لم يُؤكد نجاح بث يوتيوب الحي، ولم يُستخدم أي تجاوز للشبكة أو تسجيل دخول. اختبار Windows السابق في GitHub فشل أيضاً، وتعذر الوصول إلى السجل التفصيلي لتحديد السبب؛ لم يُؤكد نجاح البناء على Windows. راجع سجل الاختبارات النهائي في [تقرير التحديث](TV_STREAMING_PREVIEW5.md).
